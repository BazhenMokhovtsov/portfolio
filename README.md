# Portfolio website

Personal portfolio site for **Bazhen Mokhovtsov**.

## Tech

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- GitHub API (projects + language stats)

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000

Language switch:

- http://localhost:3000/?lang=en
- http://localhost:3000/?lang=de

## Deploy (Vercel)

1. Push this repository to GitHub.
2. Go to https://vercel.com/new
3. Import your repository.
4. Keep defaults (Framework: Next.js).
5. Deploy.

After deployment, each push to `main` will trigger an automatic redeploy.
